## How I work

- **Evidence first.** A result is not done merely because code runs; the data path, output, and failure modes should be inspectable.
- **Automation with guardrails.** External actions remain deliberate and reviewable—especially when an email, document, or financial conclusion is involved.
- **Good interfaces respect attention.** I prefer dense, calm software that removes busywork instead of creating a dashboard-shaped distraction.
