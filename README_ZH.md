## 我如何工作

- **证据优先。** 代码能运行不等于完成；数据链路、产物与失败模式都应该可检查。
- **自动化必须有护栏。** 特别是邮件、文档和金融结论等外部动作，必须保持审阅与控制。
- **好界面尊重注意力。** 我偏爱信息密度高而平静的软件：去掉琐事，而不是造一个仪表盘形状的干扰源。
